# FocoEstudos

## Resumo
O **FocoEstudos** é uma plataforma web e mobile para organização de estudos voltada para o ENEM, vestibulares e concursos, focada em gestão do tempo, planejamento de revisões e registro de aprendizado.

## Funcionalidades
* **Cronômetro de Foco:** Contagem e registro das horas de estudo.
* **Caderno de Erros:** Anotações de resumos e questões para revisão.
* **Calendário:** Agendamento de provas e rotina de estudos.
* **Painel Web e Mobile:** Interface de estudo para computador e acompanhamento rápido no celular.
